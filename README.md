# TestRepo
Testing first repo creation for basic commands

1. This repos is used to check the basic git commands.
2. First the clone command is tested to locally store the files.
3. Second the add, status and push command are tested to push modified files on the remote repository.
4. Third the pull command is tested to extract new files (or modified files from the remote repository).
5. Fourth the branch command on its forms is used to create a new branch separated from the main branch.
